
Split networks were calculated with SplitsTree4 and visualized with tanggle (`net.R`).

Maps were drawn based on the data from Esri (esri.com) data using the following R packages: ggspatial V1.1.10; sf V1.0.24; tidyterra V0.7.2; and maptiles V0.10.1 packages (`map.R` and `map_with_function_and_rectangles.R`).
